# Warisan-Norman-Catering-Management-System

## Overview
The Catering Management System is a web application designed to simplify the catering booking process for both customers and administrators. Customers can register accounts, view available catering packages, book events, and make payments online. Administrators can manage customers, catering packages, events, orders, and payment records through a centralized system. The project was developed using HTML, CSS, JavaScript, PHP, MySQL, and phpMyAdmin, providing an efficient and user-friendly solution for catering business management.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- phpMyAdmin
- XAMPP

## Key Features
- User Registration and Login
- Catering Package Management
- Event Booking System
- Booking Management
- Payment Processing
- Customer Information Management
- Admin Dashboard
- Database Record Management

## How to Run
1. Create a new folder in XAMPP 'htdocs' directory and move all the files inside the new folder (i recommend naming the folder into 264PROJECTS_FINALIZE)
2. run Apache and MySQL in XAMPP
3. import the database file into phpMyAdmin (food_caterer_new_5.sql)
4. Update database connection in db_connect.php (make sure the name of the database in the php file are the same with the one in phpMyAdmin)
5. Open the project in your browser: http://localhost/264PROJECTS_FINALIZE (you can change the name of the directory. here I'm using 264PROJECTS_FINALIZE)
